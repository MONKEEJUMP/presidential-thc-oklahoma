# Presidential THC Oklahoma

The official Presidential Oklahoma property at `presidentialthcoklahoma.com`.

This is a static, code-owned Next.js site with twelve registered routes, original product-first Oklahoma content, and 84 unique product images linked to matching pages on `presidentialmoonrocks.com`.

## Local commands

```powershell
npm install
npm run assets
npm run dev
```

Node 24.x is required.
